# Entity Resolution

This is an entity resolution tutorial written to work with
[TerminusDB](https://github.com/terminusdb/terminusdb) and
[VectorLink](https://github.com/terminusdb-labs/vectorlink).

In [Part1](part1/), we explore matching across records.

In [Part2](part2/), we look at comparing a set of records from two
different publication repositories for overlap.
